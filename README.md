# JavaExercises

Java exercises: Functional Interfaces, Nested Classes, and Records.

## Class list
- Exercise 1: UserForm (record), UserValidator (Predicate, lambda)
- Exercise 2: ServiceOrder (record), PriceStrategy (@FunctionalInterface), PriceCalculator
- Exercise 3: Order (static nested class OrderItem), OrderSummary (record)
- Exercise 4: LibraryAccount (inner class FineCalculator), MessagePrinter (@FunctionalInterface)

## How to run
cd src
javac *.java
java Main
